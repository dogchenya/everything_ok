# 本地工具审核页

在仓库根目录运行：

```powershell
node review/server.mjs
```

打开 http://127.0.0.1:43121/ 。保持服务运行即可继续审核。

- 直接展示 `catalog/tools.json` 中的当前发布的 17 个工具；刷新页面即可读取清单更新。
- 显示星标快照、核对日期、最近提交、入选理由和使用门槛。新入选项目在核对时均超 50,000 星；GatherPack 明确标为自有项目。
- 本地 GIF 自动循环，上游 GIF 使用远程地址嵌入；视频提供播放控件。
- “放大查看”打开图像或视频；“自行录制视频”可集中看本轮实际操作视频。支持视频拖动进度。
- 本地补录默认 2-3 倍速，关键操作保留并在结尾停留 2 秒；每张视频卡片均可打开“原速视频”逐步检查。
- “已实测并录制核心流程”“部分流程”“上游素材”“步骤 GIF”“待录”分别标注。Excalidraw 的 PNG 文件导出尚未验证成功，不计为完整实测。
- 选择结论或输入备注后自动保存到 `catalog/reviews.json`，刷新和重启服务后仍保留。
- “导出审核结果”下载 JSON，可交回当前聊天继续修改收录内容。
- 审核结论独立于候选清单，不会自动批准或发布到 GitHub。
- 外部素材受网络和原站可用性影响；加载失败会显示提示和原始链接。

审核服务只监听本机回环地址。

公开演示页位于仓库根目录 `index.html`，下载后直接用浏览器打开。当前发布排除未完成补录的 AppFlowy、RustDesk、Dify；本机原始候选与采集资料不随仓库发布。
