# 推荐工具 / Suggest a tool

填写 [推荐表单](https://github.com/dogchenya/everything_ok/issues/new?template=tool.yml)，提供：

- 项目官方 GitHub 仓库。
- 能解决什么问题，适合谁用。
- 安装要求、费用和使用限制。
- GIF 或视频演示，以及素材来源。

优先收录易上手、仍在维护的工具。缺少演示或实测失败的项目暂不收录。

Use the [suggestion form](https://github.com/dogchenya/everything_ok/issues/new?template=tool.yml). Include the official repository, purpose, intended users, setup requirements, costs and a demo with its source. Prefer maintained tools that are easy to use. Projects without working demos remain pending.
